Built for trust

Why CleanMac

A cleaner that deletes files should be careful by default. CleanMac is designed so mistakes are recoverable.

↩

Trash-first

Nothing is permanently deleted. Everything moves to the Trash with a full undo from History.

🛡

Safety denylist

Refuses to touch system paths, your Documents, and running apps - even if a rule asks it to.

📋

Rule-driven

Cleaning logic lives in editable YAML rule packs. No hardcoded magic paths buried in the app.

🔒

No telemetry, open source

Nothing leaves your machine - no tracking, no analytics. The full source is on GitHub to inspect.

Get started

Download & install

A couple of extra clicks on first launch, because this build isn't notarized yet.

● Current version: v1.0.1

  1. Download and drag to Applications. Grab CleanMac-1.0.1.dmg, open it, then drag CleanMac into your Applications folder.

  2. First launch. Right-click CleanMac.app then choose Open → Open (it's not notarized yet), or clear the quarantine flag from Terminal:

    xattr -dr com.apple.quarantine /Applications/CleanMac.app

  3. Grant Full Disk Access when asked, so CleanMac can scan the folders it needs: System Settings → Privacy & Security → Full Disk Access.
